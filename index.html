📚 How to deploy the Apps Script

  1. Open your Google Spreadsheet → Extensions → Apps Script
  2. Delete any existing code in Code.gs and paste the entire KCPH_Apps_Script.gs file
  3. Click Deploy → New deployment
  4. Type: Web app | Execute as: Me | Access: Anyone
  5. Click Deploy and copy the Web App URL
  6. Paste the URL in the field above and click Save & connect
  7. Click Test connection — you should see "Connected ✓"
